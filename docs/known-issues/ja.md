# 既知の問題

公開済みの版で確認された、未解消の問題を掲載しています。コードが修正されても、修正版が公開されるまでは掲載を継続します。

## KI-001: GitHub Actions版がmacOS・Windowsで失敗する

- **対象版**: v0.1.0（この版を指す `v0` タグを含む）
- **対象環境**: GitHub ActionsのmacOS・Windowsランナー。Linuxランナーにはこの問題はありません。
- **症状**: macOSでは空引数の処理で停止します。Windowsでは正しいアーカイブのチェックサムを不一致と判定するか、アーカイブの展開に失敗します。
- **回避策**: GitHub Actions版は `runs-on: ubuntu-latest` で実行してください。この問題はデスクトップ版やPython版の不具合を示すものではありません。
- **対応状況**: 修正コードは全3 OSの検証に成功しています。影響範囲が狭いため単独のパッチリリースは行わず、次回リリースに同梱します。修正版の版番号・公開日は未定です。

## KI-002: iOS の PWA で物理キーボードを使うと表示位置がずれる

- **対象版**: v0.1.0
- **対象環境**: iOS Safari の PWA で物理キーボードを使う場合。
- **症状**: 節を移動するたびに画面の表示位置がずれ、書いている場所が見えにくくなることがあります。
- **回避策**: ずれても本文や保存内容に影響はありません。画面を触ると表示は戻ります。
- **対応状況**: 隠し入力欄への再フォーカスを減らし、フォーカス直後にスクロール位置を復元する修正を開発版に入れました。実機での解消確認が終わり、修正版が公開された時点でこの掲載を外します。
