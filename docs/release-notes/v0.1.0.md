# novnow v0.1.0

最初の番号付きリリースです。

> Releaseワークフローは完了し、17成果物とcrates.io・TestPyPI・PyPIの公開は成功しました。ただし、公開後のGitHub Actions版smokeでmacOS/Windowsが失敗しており調査中です。全形態の動作確認完了とは扱わないでください。

## 配布物

- デスクトップ：5ターゲット × GUIあり／なしの10アーカイブ。
- Python：5ターゲットのwheel。TestPyPI・PyPIへの公開が成功しました。
- VSCode拡張：`novnow-0.1.0.vsix`。ダウンロード後、VSCodeの「拡張機能」→「…」→「VSIXからのインストール」で導入します。
- ソース：`novnow-0.1.0-source.tar.gz`（文書を含む追跡対象全体）。
- GitHub Actions：完全な版を固定する場合は `sonneko/novnow@v0.1.0`。可動の`v0`も同じリリースコミットを指しています（上記のmacOS/Windows検証失敗に注意）。

最終成果物は17ファイルと`SHA256SUMS`です。全17ファイルと照合表が添付済みです。

## 重要な注意

- v0は安定したデータ形式を保証しません。形式非互換があり得ます。v0→v1のデータ移行機能は保証しません。更新前に作品をバックアップしてください。既存本文のimport/migrate機能とは別の方針です。
- Windows/macOSの実行ファイルに配布元の署名はありません。macOSの公証も行っていません。SmartScreen／Gatekeeperの警告が出る場合があります。公式配布元と照合値を確認し、組織のセキュリティ設定を無効化しないでください。
- VSCode Marketplaceへの公開は今回は行いません。遅くとも製品v1到達までに開始する予定です。
- ブラウザ版は https://sonneko.github.io/novnow/app/ 。本番Pagesの更新状況はDeployワークフローで確認します。

## ダウンロードの照合

同じリリースの`SHA256SUMS`と照合してください。Linuxでは`sha256sum -c SHA256SUMS`、macOSでは`shasum -a 256 -c SHA256SUMS`を使用できます（対象ファイルを同じディレクトリへ揃えてください）。WindowsではPowerShellの`Get-FileHash <ファイル> -Algorithm SHA256`で該当行と比較します。照合値は改ざん検出用の署名そのものではありません。

公開前のRustテスト・実Trunk/Astroの3エンジンE2E・10デスクトップ成果物・5ターゲットwheel・3 OSのVSCode Electron検証は成功しています。FirefoxのCIはXvfb/Mesaのソフトウェア描画を使用しています。全実機のGPU・日本語IME・ファイルダイアログの挙動を保証するものではありません。
