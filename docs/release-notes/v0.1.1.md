# novnow v0.1.1

Issue #29 の仕様査定（バッチ B1〜B12・後続 X1〜X5）を実装へ入れ、プロジェクトの設定を
`project.json` から `project.toml` へ移した版。v0.1.0 の既知の問題 2 件（KI-001 / KI-002）を解消した。

## 変更点

- プロジェクトの設定を `project.toml`（`schema_version = 2`）へ移し、コメント・書式・キー順・未知キーを保つ無損失編集にした。TOML として読めない設定は上書きしない（Issue #29 B10）。
- `contents/` と `plots/` は `.cnov` だけを文書として扱い、旧形式は未知ファイルとして触れない（§5.0.9 の厳密一致）。VSCode 拡張に `.cnov` の関連付けと最低限の色付けを足した。
- 重ね物（パレット・案内・検索）の共通規則、節エディタ、ヘッダのボタンと省略、パレットの履歴と追従、キー案内のクリック実行（B1・B2・B4）。
- 案内と参照ペインの行移動、読者モードの括弧と検索の一致表示、節の分割と一体削除（B5・B6・B3）。
- 台詞内の空白の診断 W096 と、診断の有効設定を `project.toml` で編集する面（B7）。入口ページのロケール追従と iOS のフォーカス対策（B8）。
- 執筆支援の診断 W097〜W106 を実装（この版の診断は 87 種）。I051 / I058 を廃止し、W041（読み取り専用）を実装、§16.1.2（素材 URL の取得）を廃止。
- 仕様を正本とした整合（第八巡 1〜11 段）: 節ごとの undo 履歴（直近 20 節）、`api.list` の戻り値スキーマ、`plot.write` の `level`、診断の発行状況の表、操作数 121 への追随。
- 移行支援を候補提示型へ拡張し（X1）、`stage_two` を解体して `app.rs` を分割した（X3）。Shift_JIS の読み替えに `encoding_rs` 0.8.35 を採用。
- CI: develop 向け PR のプラットフォーム行列を最小スコープへ（`CI_SCOPE`）、必須チェック名から版を外す、公開後の監査を版引数に、`wheels` の `paths` にワークフローを含める。

## 互換性

- **形式の非互換**: `project.json` は読まない。`project.toml`（`schema_version = 2`）へ移った。v0.1.0 のプロジェクトを開き直す前にバックアップすること（v0 は形式の安定を保証しない。`REF:docs/specifications/external.md`）。
- 本文は `.cnov` のみ。旧形式のファイルは未知ファイルとして扱い、開かない・上書きしない。
- 診断コード: I051 / I058 を廃止、W041 と W096〜W106 を追加。
- 操作カタログ（`api.list` の `catalog_version`）は 1.1。

## 既知の問題

- 掲載中の問題: 無し。v0.1.0 の KI-001（GitHub Actions 版が macOS・Windows で失敗する）と KI-002（iOS の PWA で物理キーボードを使うと表示位置がずれる）はこの版で解消した。3 OS のランナーで複合アクションを実際に動かして確認している。
- 実機でしか確かめられない項目（IME・フォーカス・フォント・ファイルダイアログ）は `REF:docs/developers.md` §4.9 のチェックリストに残る。
- 既知の問題の一覧: <https://github.com/sonneko/novnow/blob/main/docs/known-issues/ja.md>（英語は `en.md`）

## 配布物

- デスクトップ 5 環境 × GUI あり／なし、Python wheel 5 ターゲット、VSCode 拡張（VSIX）、ソース、GitHub Actions の 5 形態。
- 照合表 `SHA256SUMS` を同じリリースに添付している。

- Rust のテスト、3 OS の VSCode 拡張（Electron）、3 エンジンのブラウザ試験、公開後の Action Smoke（3 OS）は成功。
- 実機の GPU・日本語 IME・ファイルダイアログの挙動は保証しない（§4.9）。
- Windows と macOS の実行ファイルに配布元の署名は無く、macOS の公証も行っていない。
