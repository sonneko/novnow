# novnow v0.1.2

v0.1.1 までに仕様へ書いていた実装を製品へ入れた版。ワークスペース（タブ・プロットアウトライン・
読者モード・住所録・レビュー・エージェント）と、メタデータ・メトリクス・診断・MCP・LSP の各処理が
仕様の算法どおりに動くようになった。

## 変更点

- ワークスペースの実装を仕様へ寄せた: タブ構成（`REF:src/ui/workspaces/tabs.rs`）、プロットアウトライン、読者モード、住所録、レビュー、エージェントの各ペイン。
- コア（`REF:src/core/features/`）のメタデータ・メトリクス・プロット・プロジェクト・検索・素材を仕様の算法へ合わせ、診断の発行と文言を更新した。
- 外部連携: MCP（`REF:src/cli/mcp.rs`）と LSP（`REF:src/lsp/server.rs`・`REF:src/lsp/framing.rs`・`REF:src/lsp/methods.rs`）の処理を仕様どおりにした。
- 設定の保存（`REF:src/app/settings.rs`）とセッションの扱い（`REF:src/app/session.rs`）を整理した。
- 仕様書の変更は `docs/specifications/external.md`（10 行）と `platform.md`（1 行）だけで、それ以外は実装を仕様へ寄せた。

- `.cnov` と `project.toml`（`schema_version = 2`）の形式変更は無い。
