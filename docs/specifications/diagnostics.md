**既定の有効 / 無効**

v0.1.0 の既定で **有効** なのは W080・W082・W084・W092・W095・E064・I054・I055・I056。
W081・W083・W087・W088・W089・W090・W091・W096 は **既定で無効** とし、
文体ワークスペース（§10.9）を開いたときだけ計算・表示する。
理由: これらは「書いている最中に言われたくない」種類の指摘であり、P3（ノイズを増やさない）に抵触するため。
この「既定で無効」は組み込み既定であり、設定で `"warn"` / `"error"` に変えたものは、実行コスト区分の範囲で常時出す。
有効/無効とエラー扱いの正本は `project.toml` の `[features.diagnostics]`（§4.5.2）である。作品を分け合う人同士で揃える設定であるため、`.novnow/ui.json`（個人設定）には書かない。
設定の変更は §10.9 の画面から行える（§10.9.6）。セッション限りの一時的な絞り込みは、表示フィルタ（§10.9.4）で行い、保存しない。

#### 7.2.2 台詞内の句読点直後の空白（W096）

台詞の中で句読点の後に全角空白を開ける書き方と開けない書き方が作品内で混在しているとき、少数派の箇所を指摘する。寄せ先は作者の既存の文面が作る多数派であり、どちらが正しいかを IDE は決めない。

- 対象は台詞（`「…」`）の内側だけであり、入れ子の台詞（`『…』`）の内側も台詞内として数える。地の文は数えない。
- 記号は `。`・`！`・`？` の 3 つを別々に集計する。各記号について、作品全体で「記号の次に全角空白があって同じ台詞内に文字が続く例」と「全角空白がなく同じ台詞内に文字が続く例」の合計が 5 件以上あり、多数派が少数派より 2 件以上多い場合にだけ、少数派の箇所に W096 を出す。それ以外（同数に近い場合を含む）は診断しない。
- 空白として数えるのは全角空白だけである。半角空白は「空白なし」として扱う。
- 同じ台詞内に次の文字が続かない場合（閉じ括弧の直前 `。」` など）は、集計にも診断にも含めない。
- 文章の言語は表示言語ではなく本文の文字種で決め、日本語主体でない本文ではこの診断を出さない。
- 文言は、作品内で多い側に揃っていないことを対象の記号で示す。ja: `台詞内の句読点「{0}」の後の書き方が、作品内の大勢と揃っていません` / en: `Spacing after "{0}" inside dialogue differs from the majority style in this work`。
- クイックフィックスは、多数派に合わせて全角空白を入れる、または取る 1 操作とする。
- 寄せ先を固定する設定は初版に入れない（多数派への寄せのみ）。
- W096 は執筆支援系の診断であり、組み込み既定では無効とする。有効化は `[features.diagnostics]`（§4.5.2）で行う。実行コストは、編集中は編集中の節のみを対象とし、多数派の集計だけは作品全体から取る。
