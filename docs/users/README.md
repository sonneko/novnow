# novnow ユーザーガイド

`novnow` を使う人向けの手引きです。**プログラミングの知識は要りません。**

このディレクトリの文書は、公開サイト（https://novnow.sonneko.com/）の「ユーザー向けガイド」と、
アプリの中に出る**ガイドモード**の文言の元になります。3 つは同じ内容です（手で書き写しません）。

## 読む順路

| # | 文書 | いつ読むか | 所要 |
|---|---|---|---|
| 1 | [はじめての手引き](./start.md) | はじめて開いた日。上から順に進めれば 1 本書き上がります | 約 30 分 |
| 2 | [早見表](./cheatsheet.md) | 書きながら横に置く。記号とキーだけ | — |
| 3 | [用語集](./glossary.md) | 「節って何？」と思ったとき | 都度 |
| 4 | [よくある質問](./faq.md) | 動かない・保存されたか不安なとき | 都度 |

## この手引きの前提

- **ブラウザだけで使えます。** インストールは要りません（`https://novnow.sonneko.com/app/` を開く）。
- **デスクトップ版**（Windows / macOS / Linux）もあります。画面とキー操作はブラウザ版と同じです。
- **コマンドや AI からも使えます**（CLI・LSP・MCP・Python）。ふだんは意識しなくて構いません。
  何ができるかは [よくある質問](./faq.md#ほかのソフトから使えますか) にまとめています。

## もっと詳しく知りたいとき

`novnow` の決まりごとは、すべて**仕様書**に書いてあります。この手引きの各所から、
対応する仕様書の節へリンクしています。用語は仕様書と同じ言葉を使っているので、
手引きで覚えた言葉がそのまま仕様書で通じます。

- [仕様書の一覧](../specifications/)（開発者向け。読まなくても使えます）
- [困ったときの切り分け](./faq.md)
