# 早見表

書きながら横に置いてください。記号の意味は「[本文の書き方](./start.md#3-1-節目を書く)」に説明があります。

## 本文に書く記号

| 書くもの | 意味 | 例 |
|---|---|---|
| `@01-04-02 題名` | 場面の見出し（新しい場面の始まり） | `@01-04-02 図書室の攻防` |
| `@名前` | その行を誰が言ったか（台詞の行末） | `「行くよ」@アルス` |
| `@名前:A` | 話者とモード（口調）を指定 | `「……そう」@リリア:B` |
| `'名前` | 登録済みの用語・人物・資料を指す | `'魔法学院の図書室` |
| `'M0137` | 資料を指す | `'M0137` |
| `;` | 行全体が `;` のとき、節の区切り | `;` |
| `# メモ` | その行は表示されない覚え書き | `# ここで伏線` |
| `^M0137` | 行末に資料の引用を付ける | `……と書かれている。^M0137` |
| `! 挿絵` | 挿絵の指示（表示されない） | `! ここに挿絵` |

## よく使うキー

| キー | すること |
|---|---|
| `Alt+1`〜`Alt+9` | 画面（ワークスペース）を切り替える。今の節は保たれる |
| `Ctrl+P` | 何でも呼び出す一覧（`@` 構造 / `'` 辞書 / `#` 資料 / `>` コマンド） |
| `Ctrl+G` | 番号で節へジャンプ（`010402` でも可） |
| `Ctrl+Enter` | この節を確定して次へ（無ければ作る） |
| `Ctrl+B` | 本文と話プロットを行き来する |
| `Ctrl+.` | いま出ている波線をその場で直す |
| `Ctrl+Shift+E` | 作品全体を点検する |
| `F5` | 外のソフトで変えた内容を読み直す |
| `Alt+0` | 直前に見ていた画面へ戻る |
| `?` | キーの一覧を出す |

## 画面（ワークスペース）

| キー | 名前 | 何をする場所 |
|---|---|---|
| `Alt+1` | 本文 | 書く。上に前後の節、右に関連する設定 |
| `Alt+2` | 話プロット | この話で何を書くかを決める |
| `Alt+3` | 構成 | 作品全体と章の流れ |
| `Alt+4` | アイデア | 思いつきを溜めて、後で使う形にする |
| `Alt+5` | 資料 | 調べたものを保存して本文から引く |
| `Alt+6` | 配役 | 人物・口調（モード）・役割語 |
| `Alt+7` | 読者 | 記号を消して読み返す（縦書き） |
| `Alt+8` | エージェント | AI に任せる範囲を決める |
| `Alt+9` | 点検 | 作品全体の確認と進み具合 |
