E001

Error

Unknown reference: {0}

Cause
A reference after ' does not match the dictionary.
Available action
Register a term or character, or replace it with a suggested match.
See example and resolution →

E002

Error

Malformed structure id

Cause
A structure ID or explicit reference has invalid syntax.
Available action
Correct it to a valid structure ID or reference.
See example and resolution →

E003

Error

Mode {1} is not defined for {0}

Cause
A referenced mode ID has not been defined.
Available action
Define the mode or choose an existing one.
See example and resolution →

E004

Error

Mode {1} of {0} is not available at {2} (range: {3})

Cause
A character mode is used outside its declared range.
Available action
Extend its range, add a variant, or choose another mode.
See example and resolution →

E005

Error

At most two modes per character in a section

Cause
A character has more than two modes in a section, or the same character appears twice in its mode field.
Available action
Keep only the first two modes.
See example and resolution →
