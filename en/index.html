Key Features of NovNow

Designed to structure long-form story writing and maximize immersion during creative work.

structured-writing

1. Structured Writing (Chapter/Episode/Scene/Section)

Break down long novels into Chapters, Episodes, Scenes, and Sections for seamless navigation.

Jump instantly using SceneId like '01-04-02-03'. Focus working memory on manageable ~400 word section chunks without losing sight of the epic narrative structure.

plot-prose-sync

2. Plot & Prose Synchronization

Automatically displays matching scene/section outline summaries and checklists right next to your editor.

Keep writing without straying from your outline. Eliminates the friction of toggling back and forth between outline files.

auto-reference

3. Automatic Character & World Context Popups

Detects characters and terms at the cursor position and renders personality, tone, role language, and lore.

Type ' for instant autocomplete of character names and lore terms. Character modes (e.g. A: Normal, B: Combat) adapt per section.

centralized-materials

4. Centralized Material Index & Citation Tracking

Assigns IDs (M0137/S0042) to research notes, citations, and search snapshots, traceable directly from prose.

Append ^M0137 to prose lines to track underlying research sources. Freeze and save search results as standalone research snapshot files.

ai-agent-workflow

5. Human-Controlled Gradual AI Agent Workflow

Modular AI tasks across 7 distinct roles. Humans set the exact delegation level (off / propose / apply / autonomous).

Flexibly delegate tasks: generate ideas while writing prose yourself, or request style reviews. Your human editorial vision always retains full authority.

keyboard-first-ui

6. Keyboard-First & 3-Pane Ergonomic Shell

Complete keyboard navigation without mouse reliance. Minimalist, label-free dark UI designed for uninterrupted focus.

Jump via Ctrl+G, flip between prose and the episode plot with Ctrl+B, switch panes with Ctrl+1/2/3. Eliminates UI clutter so you can immerse in prose.

text-based-data

7. Plain-Text File Format & Project Self-Containment

All manuscripts, lore, prompts, and settings saved in readable Markdown/JSON files. Simple file copy moves the entire project.

No proprietary database vendor lock-in. Edit files in any text editor, and hit F5 in NovNow to sync external changes seamlessly.

layered-architecture

8. Layered Architecture & Language Server

Strict architectural decoupling between domain novel logic (core) and UI rendering/storage adapters.

Ensures lighting-fast performance and crash resiliency, safeguarding your hard-earned manuscript from data corruption.
