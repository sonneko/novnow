Startup & Project Structure

Error: 'This directory is not a novnow project' on startup

Symptoms & Issue

When attempting to open a directory, the GUI does not launch and prints missing file errors to terminal.

Root Cause

One or more required project files (e.g., project.toml, characters.md, words.md, materials/index.json, plots/all.cnov) are missing.

Resolution

Run novnow new . inside the directory to generate boilerplate project files, or create a project using the starter modal.

Migration

Cannot open legacy projects (characters.json detected)

Symptoms & Issue

Opening a legacy directory results in a legacy format error.

Root Cause

NovNow v0.1.0 uses characters.md instead of legacy characters.json.

Resolution

Keep the original project unchanged and use its compatible older release to export plain text. Project format compatibility is not guaranteed before v1, and no v0-to-v1 migration feature will be provided. The CLI migrate command imports prose text into a new project; it does not convert old project formats.

Diagnostics & Syntax

Red wavy line under character mode (E003 / E004)

Symptoms & Issue

Error wavy lines appear under mode: fields or speaker annotation @Character:Mode.

Root Cause

E003: The mode ID is not defined in characters.md. E004: Assigned outside the mode's valid SceneId range.

Resolution

Open quick fix (Ctrl+.) to expand the range: in characters.md or replace with an existing defined mode.

AI Agent & MCP

E030 / E063 / E064 when executing AI tasks

Symptoms & Issue

AI task execution fails with missing environment variables or unreachable MCP server messages.

Root Cause

E030 means a missing MCP environment variable; E063 means the MCP server is unreachable; E064 means the local LLM is unreachable.

Resolution

For MCP, check agents/mcp.json, the required environment variables, and the server process. For a local LLM, check its endpoint in the agent workspace. The browser cannot launch desktop-only stdio servers.

Web Version & Storage

Web Version: 'Storage is unavailable in this environment'

Symptoms & Issue

Opening the web version displays a full-screen storage error preventing editor launch.

Root Cause

IndexedDB access is disabled due to Private/Incognito browsing or browser security settings.

Resolution

Open NovNow in a standard browsing window, allow storage access, or use the Desktop version.

Encoding & UTF-8

Garbled characters or encoding errors after external editing

Symptoms & Issue

ProjectError::Encoding error prevents opening modified project files.

Root Cause

An external text editor saved files in Shift_JIS or UTF-16 instead of UTF-8.

Resolution

Re-open the file in VS Code or any editor, save as UTF-8 (BOM and CRLF are also accepted), and press F5 in NovNow.
