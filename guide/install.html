novnow の入れ方（どの版を選ぶか）

novnow には 5 つの入り方があります。むずかしい準備が要るのは、デスクトップ版と VSCode 拡張版だけです。

いまの状態: ブラウザ版は今すぐ使えます。ほかの 4 つは公開の準備中です。 この手引きは、公開されたときに同じ手順で入れるように書いています。

1. どれを選ぶか（1 分）

入り方 向いている人 準備
ブラウザ版 まず試したい人。インストールしたくない人 要りません
デスクトップ版 手元のフォルダに原稿を置きたい人 ファイルを 1 つ落とします
VSCode 拡張版 ふだん VSCode で書いている人 VSCode が要ります
Python ライブラリ版 Python から操作を自動化する人 Python が要ります
GitHub Actions 版 点検や書き出しを自動で回す人 GitHub のリポジトリが要ります

はじめての人は、ブラウザ版から始めてください。作品はブラウザの中に保存されます。

画面とキー操作は、どの版でも同じです。作品のフォルダは、版を変えてもそのまま使えます。

2. ブラウザ版（インストール不要）

  1. ブラウザで https://novnow.sonneko.com/app/ を開きます。
  2. 作品の一覧が出たら「＋ 新規作成」を押します。
  3. 名前を入れると、そのまま書き始められます。
  • 一度開けば、ホーム画面に追加してオフラインでも起動できます（PWA）。
  • 作品はブラウザの中（IndexedDB）に保存されます。
  • ブラウザのデータを消すと、作品も消えます。書き上がったら Zip で書き出してください。

3. デスクトップ版

デスクトップ版には 20 通りの組み合わせがあります。次の 2 つの質問に答えるだけで、使うファイルが 1 つに決まります。

3.1 質問 1: 窓（画面）は要りますか

  • 要る: ふだん使うならこちらです。窓の中で書けます。コマンドからも使えます。
  • 要らない: コマンドやほかのソフトから使うだけならこちらです。軽くて余計な窓が出ません。

3.2 質問 2: 同じパソコンで 2 つ以上を同時に開きますか

  • 開かない: 「1 つだけ」の版を選びます。2 つ目を開こうとすると「すでに起動しています」と出ます。
  • 開く: 「同時に開ける」版を選びます。別々の作品を並べて開けます。

3.3 パソコンの種類を選ぶ

パソコン ファイル名の例
Windows（ふつうの Windows） novnow-0.1.0-x86_64-pc-windows-msvc-gui-single.zip
Mac（Apple のチップ） novnow-0.1.0-aarch64-apple-darwin-gui-single.tar.gz
Mac（Intel のチップ） novnow-0.1.0-x86_64-apple-darwin-gui-single.tar.gz
Linux（ふつうの PC） novnow-0.1.0-x86_64-unknown-linux-gnu-gui-single.tar.gz
Linux（ARM の機械） novnow-0.1.0-aarch64-unknown-linux-gnu-gui-single.tar.gz

名前の後ろの gui は窓あり、nogui は窓なしです。single は 1 つだけ、multi は同時に開ける版です。

3.4 入れ方（4 段階）

  1. 公開ページ（GitHub の Releases）を開きます。
  2. 上の表と同じ名前のファイルを落とします。
  3. 落としたファイルを、好きなフォルダで展開します。
  4. 出てきた novnow をダブルクリックします（Windows は novnow.exe）。
  • インストーラはありません。展開するだけで使えます。
  • PATH の追加や、ファイルの関連付けは行いません。
  • Mac の窓あり版には novnow.app が入っています。これを開いてください。
  • Linux では、展開した novnow に実行の権限が付いています。

3.5 警告が出たとき

  • Mac: 「開発元を確認できません」と出たら、システム設定の「プライバシーとセキュリティ」を開きます。下のほうの「このまま開く」を押します。
  • Windows: 「Windows によって PC が保護されました」と出ることがあります。そのときは「詳細情報」を押し、次に「実行」を押します。
  • どちらも、配布元の署名が付いていない間だけ出ます。

3.6 2 つ目が開かないとき

「1 つだけ」の版では、2 つ目を開くと「すでに起動しています」と出て終わります。これは故障ではありません。

先に開いている窓を使ってください。窓が前に出ないときは、タスクバーや Dock から選びます。

3.7 消したいとき

展開したフォルダを削除するだけです。パソコンの中に設定は残りません。

「最近開いた作品」の一覧だけは、次の場所に残ります。消してよいファイルです。

  • Windows: %APPDATA%\novnow\recent.json
  • Mac: ~/Library/Application Support/novnow/recent.json
  • Linux: ~/.local/state/novnow/recent.json

4. VSCode 拡張版

  1. VSCode を開き、左の「拡張機能」を押します。
  2. novnow で検索し、sonneko.novnow を入れます。
  3. novnow の作品フォルダを VSCode で開きます。
  • 作品フォルダを開くと、診断や補完が使えます。
  • novnow 本体が入っていないときは、拡張機能が自動で 1 つだけ落としてきます。
  • 落としてきた本体は、作品のフォルダの外（拡張機能の保存場所）に置かれます。
  • 会社のネットワークなどで自動の取得を止めたいときは、設定の novnow.autoDownload を切ります。
  • 本体の場所を自分で決めたいときは、設定の novnow.executablePath に書きます。

使える操作は「点検」「書き出し」「新規作成」「言語サーバの再起動」の 4 つです。

5. Python ライブラリ版（プログラマ向け）

Python から novnow の操作を呼べる形です。手で書くための画面はありません。

pip install novnow
python -c "import novnow; print(novnow.__version__)"
  • 対応は Python 3.9 以降です。Windows・Mac・Linux の 5 つの環境に向けて配ります。
  • 版を固定するときは pip install novnow==0.1.0 のように書きます。
  • ネットワークに出られない環境では、落としたファイルを直接指定して入れられます。

6. GitHub Actions 版（自動化したい人向け）

GitHub のリポジトリで、点検や書き出しを自動で回せます。ふだんの執筆では使いません。

- uses: sonneko/novnow@v1
  with:
    path: .
    command: check
  • 点検でエラーが出ると、その仕事は失敗します。警告だけなら成功します。
  • 版は with: の version で固定できます。
  • GitHub の外へ原稿を送ることはありません。取得のときだけ通信します。
