API リファレンス

novnow の機能は 121 の正規操作（canonical operation）に整理されていて、Rust API・Python・LSP・MCP・CLI の 5 つの口から同じ実装を呼び出せます。この表は仕様書 §19.7 の写しで、引数と戻り値のキーは `api.list`（§19.8.2）から取り、CI が実装と突き合わせています。

呼び出し方

# CLI（§19.6）
novnow section list novel --json
novnow api list --json

# Rust（§19.2）
let mut session = Session::open("novel")?;
let data = session.run("section.list", json!({}))?;

# Python（§19.3）
with novnow.open("novel") as session:
    data = session.run("section.list")

# MCP（§19.5）
tools/call { "name": "novnow.section.list", "arguments": {} }
