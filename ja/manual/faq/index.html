よくある質問

使い始め

何から始めればいい？

はじめての手引き を上から順に進めてください。30 分で 1 本書き上がります。

インストールは必要？

ブラウザ版は不要です。https://sonneko.github.io/novnow/app/ を開くだけです。 デスクトップ版なども公開済みです（入れ方）。

無料？ あとで有料にならない？

無料です。仕様も実装も MIT ライセンスで、有料化の予定はありません （ライセンス）。

スマホやタブレットで使える？

ブラウザ版はタブレットのブラウザでも開けますが、キーボード操作が前提の画面です。 スマホでの利用は想定していません。

保存とバックアップ

保存は自動？

はい。書いた内容は自動で保存されます。保存されないのは「読んでいるだけ」のときだけです。

保存の状態は画面の下に出ます。

保存されたか確かめたい

画面の下（ステータスバー）を見てください。Ctrl+S で今すぐ書き出すこともできます。

ブラウザ版のデータはどこにある？

ブラウザの中（IndexedDB）です。ブラウザのデータを消すと作品も消えます。 右上のメニューから「Zip 書き出し」で、作品まるごとを 1 ファイルにして保管してください。

パソコンを変えたい

Zip で書き出して、新しい環境で「Zip 読み込み」をします。デスクトップ版ならフォルダごとコピーでも構いません。

外のソフトで原稿を直したら

F5 を押すと読み直します。両方で同じ場所を変えていた場合は、差分を見て選べます。

画面と操作

波線が出た。消したい

赤・黄・青の波線は注意の印で、原稿そのものは壊れていません。

  1. 波線の上にカーソルを置き、Ctrl+. を押します。
  2. 出てきた候補から選ぶと直ります。候補が合わなければ、そのまま書き換えてください。
  3. 一覧で見たいときは Alt+9（点検）へ。

意味が分からないコード（E001 など）は よく出るエラーと直し方 か 診断の一覧 で調べられます。

' の後ろに候補が出ない

その名前がまだ登録されていません。Ctrl+. から用語・人物として登録するか、 Alt+6（配役）で人物を作ってください。

キーを忘れた

? を押すとキーの一覧が出ます。印刷したいときは 早見表 を。

文字が小さい / 大きい

Ctrl+Plus で大きく、Ctrl+Minus で小さく、Ctrl+0 で元に戻ります。

色を変えたい

Ctrl+Alt+T で「システムに合わせる → 暗い → 明るい」を切り替えます。

英語にしたい

Ctrl+Alt+L で日本語と英語が入れ替わります。作品の中身は変わりません。

前の画面に戻りたい

Alt+0 です。もう一度押すと 2 つの画面を行き来します。

書き方

; って何のためにある？

「ここで節が変わる」という印です。行全体を ; だけにすると区切りになります。 表示されず、書き出すときも残りません（早見表）。

記号を消して読みたい

Alt+7（読者）に切り替えてください。記号が消えて縦書きで読めます。

章や話の番号は変えられる？

番号は「章 → 話 → 場面 → 節」の並びを表しています。話を足すと番号も増えます。 番号の決まりは 仕様: 構造 ID §4.1 にあります。

ルビは振れる？

読者モードでルビの設定ができます（仕様: 読者モード §17.3）。 本文には書き込みません。

AI について

AI が勝手に書き換えることはある？

ありません。既定は「提案まで」で、あなたが差分を見て承認したときだけ反映されます。 Alt+8（エージェント）で役割ごとに任せ方を変えられます。

AI を使わなくても使える？

使えます。AI の機能はすべて切った状態でも、執筆・点検・書き出しは普通に動きます。

ほかのソフトから使えますか

novnow は画面（GUI）だけのアプリではなく、同じ機能が別の入口からも使えます。 ふだん使わなければ覚える必要はありません。自動化や、ほかのエディタとの連携に使えます。

入口 何ができるか 誰向け
画面（GUI） すべて ふつうに書く人
ブラウザ GUI と同じ（インストール不要） まず試したい人
コマンド（CLI） 作成・診断・書き出し・取り込み 大量の原稿をまとめて処理したい人
エディタ連携（LSP） 補完・定義へ移動・診断を他のエディタで VS Code などを使っている人
AI 連携（MCP） AI から作品を読む・提案を受ける AI と組み合わせたい人
Python 同じ操作をプログラムから 自動化したい人

詳しくは 仕様: 外部インターフェース §19 を参照してください。
