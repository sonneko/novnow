assets/ の中身の扱い: 起動時に assets/ 配下のファイルを読み込み、アイコンの表示（§5.5.3）に使う（space: の外部ファイルは assets/ も含むテキストとして読む。§5.3.6）。1 ファイル 256KB を超えるものは中身を保持しない（アイコンなら W069。§5.5.3）。デスクトップ版はファイルをそのまま読み、Web 版は IndexedDB の bytes（Zip の取り込みで入ったもの）から読む（§13.3.2）。したがってどちらの版でもアイコンは表示できる。

「無言で作成」も 書き込みはプロジェクトルート配下に限る（§13.1）。読み取り専用メディア上では作成を省略し、W041 を出して続行する。

読み取り専用の判定（W041）: 開いたときに プロジェクトの中へ 1 回だけ試し書きをして決める （.novnow/ の下に空の .write-probe を作り、すぐ消す。作った .novnow/ が元から無ければ一緒に消す）。 モードビット（-w）ではなく実際に書けるかを見るのは、読み取り専用でマウントされた媒体・ 書き込みを拒否するサンドボックス・容量の尽きた領域を同じ扱いにするためである。パスはプロジェクトの 中だけ（§13.1）で、失敗しても何も残らない。判定はプロセス（Session）ごとに 1 回で、毎回は試さない。 書き込みを試す判定なので、novnow check も 1 回だけ書く（check の方針「何も書かない」の例外。 書けなければ何も書かない）。読み取り専用のときの挙動:

  • 自動作成（ideas.md / materials/docs/ / agents/ / exports/ / .novnow/）と、既定プロンプトの 書き出し（§15.5.4 の I050）をしない（作成を省略して続行する）。
  • W041 を出す。出す場所は、novnow check の 1 行（<ルート>: W041 文言）、project.validate と diagnostics.run（scope を指定しないプロジェクト全体のとき）の diagnostics の 1 件（path は空、 line / column は 0）、GUI を開いたときのステータスバーの通知の 3 つ。波線は出さない （文書の中の位置を持たない、§7.1 と同じ扱い）。
  • 編集・保存は試すだけ（保存を試みて失敗したら SaveFailed。§8.2）。W041 を理由に編集を止めない。

実装状況の注記: いま自動作成を行うのは novnow new（テンプレート一式）と、prompts/ の欠けた既定プロンプト（開いたときと novnow mcp の起動時。§15.5.4。I050 を通知）だけである。既存プロジェクトを開いたときの ideas.md / materials/docs/ / agents/ の「無言で作成」は未実装。無い任意のパスは「無い」まま動く（ideas.md が無ければ着想は空、materials/docs/ が無ければ資料ファイルを置く場所が無いだけ）。

4.3 プロジェクト妥当性の判定

  1. 必須パスの存在確認（上表）。欠落が 1 件でもあれば ProjectError::Incomplete { missing: Vec<PathBuf> }。
  2. project.toml の schema_version 検査。
    • 2（または省略）→ OK
    • >2 → ProjectError::TooNew { found }（novnow 本体の更新が必要）
  3. 文字コード検査: 文書として認識するすべてのファイル（§5.0.9）が UTF-8 として妥当。不正バイトがあれば該当ファイルを列挙して ProjectError::Encoding。
  4. 以降のパース失敗（構文エラー）は 起動失敗にしない。診断として表示し（JSON / TOML がパースできないときは E025、§7）、該当ファイルは「部分的に壊れた文書」として開く（P4: 作家の原稿を人質に取らない）。原文は書き換えない（MUST）。
  5. 仕様が定義しないファイル・ディレクトリ（§5.0.9 が文書として認識しないものを含む）は妥当性判定の対象にしない。novnow が書くのは仕様が定義するパスだけで、未知のものを削除・改名・上書きしない（MUST）。旧形式のファイル（project.json、contents/*.txt、plots/*.txt）も未知のファイルとして扱うため、旧形式のプロジェクトを開くと必須ファイルの不足として通常のエラーになる。旧形式の特別検出や自動変換は行わない。

補足:

  • project.toml が TOML として読めない（または schema_version が数でない）ときは 2. を飛ばす。版が読めないことは起動失敗にせず、4. のとおり E025 を出して既定値で開く。壊れた project.toml は上書きしない（§4.5）。
  • core は I/O を持たない（§3.2）。存在するパスの一覧・project.toml の中身・UTF-8 として不正なファイルの一覧はストレージ層（adapters）が集めて渡し、validate は判定だけを行う。Web（IndexedDB、§13.3）にはディレクトリが無いので、必須ディレクトリは常に存在するものとして扱う。

4.4 .novnow/（ローカル状態）

プロジェクト内に置くが、VCS へのコミットは推奨しない（novnow new が生成する .gitignore に .novnow/ と exports/ を含める）。 .novnow/ に置くのは、揃える必要のない個人の表示・操作の好みと、全 feature に共通する粗い表示設定に限る。診断の有効性やエラー扱いなどの feature 単位の設定は、作品として揃える設定として project.toml の [features]（§4.5.2）に置き、ここには置かない。

4.4.1 .novnow/ui.json

{
  "schema_version": 1,
  "theme": "system",
  "language": "system",
  "reference_pane_side": "right",
  "last_scene": "01-04-02-03",
  "pane_ratio": { "main": 0.62, "context_view": 0.55 },
  "font_scale": 1.0,
  "inlay_hints": true,
  "suggest_comma": false,
  "status_stats_mode": false,
  "confirm_section_delete": true,
  "guide_done": false,
  "context_sections": 3,
  "autosave_ms": 400,
  "folded": { "outline": ["@02", "@03"], "context_view": [] }
}

theme: "system" | "dark" | "light" / language: "system" | "ja" | "en"。 autosave_ms: 自動保存までの打鍵の間隔（§8.2、200–2000、既定 400。範囲外は丸める）。 suggest_comma: 自動句切れ提案（§9.4.3、既定 false）。 status_stats_mode: ステータスバーの統計モード（§9.6.3、既定 false）。 confirm_section_delete: 空でない節の削除前に確認するか（§8.1.2、既定 true）。 guide_done: はじめての手引きを閉じたか（§9.10、既定 false）。true なら自動では出さない。 知らないキーは読んだまま書き戻す（将来のキーを、古い版が消してしまわないため）。 範囲を持つキーは、範囲外の値を読んだときに読み捨てるか範囲へ丸める（pane_ratio・font_scale・autosave_ms・max_line_chars は丸め、context_sections は範囲外なら既定 3 のまま）。型の違う値は読み捨てる。

キー 既定 範囲
pane_ratio.main 0.62 0.3–0.85
pane_ratio.context_view 0.55 0.2–0.8
font_scale 1.0 0.8–1.6（Ctrl+Plus / Ctrl+Minus は 0.1 刻み）
context_sections 3 1–9
autosave_ms 400 200–2000
max_line_chars 表示言語ごと（§4.4.5） 20–120

folded: 折りたたみ状態（§9.3.3）。2 つの配列を持つ。

キー 内容
outline 構成ツリー（§10.3.1）で話を展開している章の鍵（@NN）。構成ツリーは既定で畳んだ状態から始まるので、開いている章を並べる（§9.3.3 の注記）
context_view 文脈ビュー（§9.3）で畳んでいる節の鍵（@AA-BB-CC-DD）。現在の節を含む単位（鍵が現在の節 ID の接頭辞）は保存しない（§9.3.3「現在の節を含む単位は畳めない」）
  • 既に無い章・節の鍵は、描画で参照されないだけなので害は無い（起動時に消しには行かない。ファイルを書き換えない、§4.5）。
  • 旧名 folded.context は読むときだけ受け付ける（書き出しは常に context_view）。 このファイルが存在しない／壊れている場合は既定値で起動し、エラーを出さない（MUST）。

4.4.2 .novnow/stats.json（執筆統計の最小メタデータ）

§9.6.2 のセッション情報と §10.9.5 の統計タブのために、日次の集計だけ を保持する。

{
  "schema_version": 1,
  "days": {
    "2026-10-09": { "chars": 3800, "hours": [9, 10, 22, 23] }
  }
}
規則 内容
粒度 1 日 1 レコード。chars は当日の増加文字数（空白除外）、hours は執筆のあった時刻（0–23）の集合
イベントログを作らない（MUST） *.jsonl 形式の打鍵・保存ログは一切作らない。内容・文面・ファイル名は記録しない
保持期間 直近 400 日。超えた分は削除する
サイズ上限 64KB。超えたら古い日から削る
欠損耐性 削除・破損しても 統計の履歴が消えるだけ。他の機能に影響してはならない（MUST）
書き込み頻度 セッション終了時と 10 分ごと。打鍵ごとには書かない

4.4.3 .novnow/reader.json

読者モードの読書位置・文字サイズ・列数・しおりを保持する。原稿・共有設定とは独立したローカル状態であり、 削除しても読書位置が初期化されるだけである。未知のキーは保持する（読み書きのたびに温存し、既知のキーだけ上書きする）。

キー 型 既定 範囲（外は丸める） 意味
episode 整数 0 話数に収める 開いている話（章・話の昇順に並べた索引。パス順ではない）
page 整数 0 — 話の中のページ
font_size 実数 20.0 12.0〜36.0 本文の文字サイズ（.novnow/ui.json の font_scale とは独立、§17.3）
columns 整数 18 5〜40 縦書きの列数（横書きでは 1 行の字数の目安）
vertical 真偽 true — 縦書き（false で横書き）
ruby 真偽 true — ルビを表示する
dark 真偽 false — 読者モードだけ暗色にする
bookmarks 配列 空 — しおり。[[文書パス, ページ], …] の配列で、b を押すと今の位置を付け外しする（同じ組があれば外す）。§17.3.4
  • 既定値の出どころは project.toml の [reader]（§4.5）が先で、reader.json にキーが無いときだけ使う。 ただし columns は reader.json → [reader] columns → 18、ruby は reader.json → [reader] ruby → true の順。 1 段の字数（行数）は reader.json には持たず、[reader] chars_per_column（既定 42、10〜80）だけを見る。
  • 壊れた JSON（オブジェクトでない・読めない）は空の設定として扱い、既定で開く（診断は出さない。§4.4 冒頭）。
  • 保存は整形した JSON（2 字下げ）＋ 末尾の改行。値が変わったときだけ書く。

4.4.4 .novnow/cache/

解析キャッシュ（再生成可能。削除しても動作に影響してはならない）。

4.4.5 本文の 1 行最大文字幅（max_line_chars）〔状態: 実装完了〕

  • .novnow/ui.json に任意キー max_line_chars（整数、有効範囲 20..=120、範囲外はクランプ）を追加する。
  • 未指定時の既定値は、日本語表示（ja）では全角 44 字相当、英語表示（en）では半角 70 字前後相当とし、言語ごとの字面幅に応じて右側に不自然な余白が残らないようにする。コマンドパレットからも変更できる。

4.5.2 [features]（feature 単位の設定）

  1. 個別の診断コード（例: W083 = "off"）
  2. グループ: structure（§7）/ storage（§7.1）/ writing（§7.2）
  3. default
