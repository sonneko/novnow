起動・プロジェクト構造

起動時に「このディレクトリは novnow プロジェクトではありません」とエラーが出る

症状・事象

コマンドラインまたはフォルダ選択でプロジェクトを開こうとすると、画面が起動せずに終了メッセージが表示される。

原因

NovNowの必須ファイル（project.toml, characters.md, words.md, materials/index.json, plots/all.cnov など）のいずれかが不足しています。

解決方法

対象フォルダ内で novnow new . を実行して必須ファイルを自動生成するか、新規プロジェクト作成メニューからフォルダを開き直してください。

novnow: このディレクトリは novnow プロジェクトではありません
  不足しているもの:
  - project.toml
  - characters.md
  - plots/all.cnov
バージョン移行

旧形式のプロジェクト（characters.json）が開けない

症状・事象

旧版のプロジェクトフォルダを開こうとするとエラーになり起動しない。

原因

NovNow v0.1.0 は characters.json ではなく characters.md を使用する新しいファイル形式を採用しています。

解決方法

元の作品は変更せず、対応する旧版で開いて本文を通常のテキストに書き出してください。v1 までは形式互換性を保証せず、v0 → v1 の移行機能も提供しません。CLI の migrate は本文テキストを新しい作品に取り込む機能で、旧形式の自動変換ではありません。

構文・診断エラー

キャラのモード設定で赤波線（E003 / E004）が表示される

症状・事象

話プロットの mode: フィールドや本文の注釈 @リリア:C にエラー波線が引かれる。

原因

E003: 指定したモードIDが characters.md に未定義、E004: モードの有効範囲 (range: @01 .. @02) 外の節で割り当てられています。

解決方法

クイックフィックス (Ctrl+. または電球アイコン) を押し、characters.md の range: を拡張するか、既存のモード名へ置換してください。

AIエージェント・MCP

AIエージェント実行時に E030 / E063 / E064 が出る

症状・事象

プロット生成や本文執筆タスクを実行すると「環境変数が設定されていません」「MCPに接続できません」と表示される。

原因

E030 は MCP 用の環境変数が未設定、E063 は MCP サーバへの接続失敗、E064 はローカル LLM への接続失敗です。

解決方法

MCP は agents/mcp.json の設定とサーバの起動を確認してください。ローカル LLM は agent ワークスペースで接続先を確認します。Web 版からデスクトップ専用の stdio サーバは起動できません。

Web版・ストレージ

Web版で「この環境ではデータを保存できません」と表示される

症状・事象

ブラウザでWeb版NovNowを開いた際、全画面メッセージが表示されて起動できない。

原因

プライベートブラウジングモードやブラウザ設定によって IndexedDB へのアクセスが遮断されています。

解決方法

通常ウィンドウで開き直すか、サードパーティCookie/ストレージ制限を解除してください。またはデスクトップ版をご利用ください。

ファイル文字コード

外部で編集したファイルの文字が化ける / 読み込めない

症状・事象

ProjectError::Encoding が発生し、プロジェクトの一部ファイルが開けない。

原因

外部のテキストエディタで保存した際、Shift_JIS や UTF-16 などのUTF-8以外の文字コードで保存されています。

解決方法

VS Codeやテキストエディタで該当ファイルを開き、文字コードを「UTF-8」で保存し直して F5 キーを押してください。
