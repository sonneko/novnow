書き出した原稿を公開する

novnow は投稿サイトへの投稿までは行いません。書き出したファイルを、ふだん使っている サイトに貼るところまでで、作業は完結します。

1. 書き出す

  1. Ctrl+P を押し、> に続けて export と打ちます。
  2. 形式を選びます。
  • テキスト（`.txt`）: 投稿サイトに貼るだけならこれ。
  • Markdown（`.md`）: 見出しや強調を使いたいとき。
  1. 保存先を選ぶと、@ や ' などの記号がすべて取り除かれた原稿ができます。

2. 公開する

できたファイルを開いて、中身をまるごとコピーし、投稿サイトの本文欄に貼ります。 章ごとに分けたいときは、範囲を指定して書き出します（--range @01 .. @03）。

3. 自動で公開したい場合

GitHub を使うと、原稿を更新するたびに自動でサイトへ反映する仕組み（GitHub Actions）を 組めます。これは開発者向けの話なので、ふつうは必要ありません。

novnow はこの仕組みを内蔵せず、案内だけを出します。設定のしかたは GitHub の ドキュメントを参照してください。

公開前に確かめたいこと

  • Alt+9（点検）で、エラーが 0 件か確認する
  • Alt+7（読者）で、記号を消した状態を読んでみる
  • 書き出したファイルを開いて、1 行目から最後まで読めるか確かめる
