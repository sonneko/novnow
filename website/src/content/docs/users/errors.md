本文に波線が出たときは、このページを見てください。**コードごとに直し方が決まっています。**

コードの一覧は [診断の一覧](https://sonneko.github.io/novnow/ja/diagnostics) にあります。ここでは、書きながら
よく出る 12 件だけを、直す順番で並べます。

## 直すときの基本

1. 波線の上にカーソルを置いて `Ctrl+.` を押します。
2. 候補が出たら選びます。合わなければ、そのまま書き換えます。
3. 全部まとめて見たいときは `Alt+9`（点検）を開きます。

## 参照のエラー

### `E001` 辞書にない参照です

`'` の後ろの名前が、まだ登録されていません。

- その名前を**用語か人物として登録**します（`Ctrl+.` の候補から選べます）。
- 打ち間違いなら、正しい名前に直します。似ている候補が `Ctrl+.` に出ます。

### `E012` 登場人物がいません

台詞の行末に書いた `@名前` の人物が、`characters.md` にいません。

- `Alt+6`（配役）で人物を作ります。
- 名前の綴りが合っているか確かめます。空白や記号の違いでも別の名前になります。

## 構造のエラー

### `E002` 構造 ID の形式が不正です

`@01-04-02` のような番号の書き方が崩れています。

- 桁数をそろえます（`01-04-02`。`1-4-2` は通りません）。
- 章・話・場面・節の順番を確かめます。

### `E008` 重複しています

同じファイルの中で、同じ番号を 2 回使っています。

- 後のほうの番号を、まだ使っていない番号に変えます。
- `Ctrl+G` でその番号へ飛べます。

### `W002` 裸の `@` があります

行の途中に `@` だけが書かれています。`@` は行の先頭か行末で使います。

- 行末の話者注釈にしたいなら、行の最後へ移します。
- 記号として書きたいなら、`@` の前に `\` を置きます。

### `W030` プロットと本文の節数が違います

話プロットに書いた節と、本文の節の数が合っていません。

- `Alt+2`（話プロット）で、足りない節の行を足します。
- 本文を消したなら、プロットの行も消します。

### `W012` 空の節があります

節の見出しだけがあって、本文がありません。

- その節に 1 行書くか、節ごと消します。
- 書き出す前に `Alt+9` で残りを確かめられます。

## 人物とモードのエラー

### `E005` 1 節で同じ人物に設定できるモードは 2 つまでです

- 先頭の 2 つだけが使われます。3 つ目を消すか、節を分けます。

### `E003` モードが定義されていません

`@リリア:B` の `B` が、その人物にまだありません。

- `Alt+6`（配役）でモードを足します。
- 既にあるモードの名前に直します。

## 資料のエラー

### `E007` 資料が存在しません

`'M0137` の ID の資料がありません。

- `Alt+5`（資料）で ID を確かめます。
- 新しく資料を作るなら、その画面から追加します。

### `E006` 資料のタイトルが一致しません

資料のファイル名と、索引に書いた題名がずれています。

- 索引の題名を、ファイルの 1 行目に合わせます。

## ファイルのエラー

### `E025` JSON が読めません

`project.json` などの形が崩れています。**開く前に壊れていると、画面が出ません。**

- 直前のバックアップ（Zip）から戻します。
- 手で直すなら、`,` と `"` の数を確かめます。迷ったら戻すほうが安全です。

## それでも直らないとき

- `Alt+9`（点検）で、エラーの全文と場所を見ます。
- [よくある質問](/ja/manual/faq) と [トラブルシューティング](https://sonneko.github.io/novnow/ja/troubleshooting) も見てください。
- 仕様の正確な条件は [診断カタログ](/ja/specifications/diagnostics) §7 にあります。
