Git は、**変更の歴史を残す道具**です。`novnow` は Git を内蔵していませんが、
作品がただのテキストのフォルダなので、そのまま Git で管理できます。

**使わなくても構いません。** バックアップだけなら、[Zip で書き出す](/ja/manual/start#export)か、
フォルダをコピーするだけで足ります。

## Git を使うと何がうれしいか

- 「昨日の状態に戻す」ができる（変更を記録しているため）
- どこをどう変えたかが行単位で分かる
- GitHub などに置けば、別のパソコンでも同じ原稿を開ける

## 最小限の手順

```bash
cd わたしの作品
git init
git add .
git commit -m "書き始め"
```

以降は、区切りがついたときに次の 2 行を繰り返すだけです。

```bash
git add .
git commit -m "第 1 話を書き終えた"
```

## 何を記録しないか

`.novnow/` は画面の状態とキャッシュなので、記録しません。
`novnow new` で作った作品には、最初から `.gitignore` が入っていて `.novnow/` を除外しています。

## 注意

- `novnow` は Git の状態を画面に表示しません（入っているかどうかを気にせず書けます）。
- コミットは**自動では行いません**。自分で区切りをつけて実行してください。
